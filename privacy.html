Privacy Policy

Last Updated: August 30, 2026

At PrintPrice, accessible via printpricecalc.netlify.app, the privacy of our ecosystem visitors is paramount. This Privacy Policy clarifies the parameters governing underlying client processing metrics and external data interfaces.

1. Local Processing Architecture

PrintPrice runs entirely on your local hardware container as an offline-capable utility. Every metric typed into the slicing framework configuration matrix remains enclosed inside your localized sandboxed web environment:

  • Calculation variables (material weight configurations, local electricity billing parameters, and production overhead rates) are compiled directly within your running browser process loop.
  • No calculation data arrays are transmitted over internet protocols or mirrored onto remote cloud infrastructures.
  • Persistent histories, preset slots, and baseline values are committed strictly to local browser storage engine partitions (localStorage). You can drop these tables at any time by executing a clear utility run inside your application options layout.

2. System Diagnostic Infrastructure

Standard payload transmission rules apply over network channels during site resolution events. Netlify (our continuous delivery framework pipeline network) processes raw node telemetry metrics during connection queries. These system trace entries include network protocol addresses (IP addresses), user-agent strings, internet service namespaces, timestamp counters, and referral entry paths. These vectors are handled anonymously solely to inspect operational runtime conditions, prevent interface failures, and monitor platform integrity.

3. Integrated Advertising Engine & Tracking

We leverage Google AdSense integrations to sustain the computing deployment baseline of this interface tool layer. Please evaluate the operating criteria of these contextual integrations:

  • Google, as an independent vendor provider, updates user cookie allocations to serve programmatic media blocks based on prior interactions across this utility or other network routes.
  • These tracking definitions let advertising modules serve relevant inventory profiles to your viewport window.
  • You can toggle off behavioral programmatic tracking arrays at any point by configuring your parameters directly on the official Google Ads Preferences Center.
  • Regional users originating from within European territories are presented with regulatory control mechanisms to configure or restrict advertising storage profiles explicitly before script run initialization.

4. Compliance Framework Protections

Pursuant to international data rules (GDPR, UK Data Protection Acts, and local consumer frameworks), you maintain fundamental control permissions. Because PrintPrice does not ingest or retain permanent target profiles matching natural identities inside centralized systems, your rights over locally managed client records can be instantly resolved. You can purge local calculation histories completely by clicking the "Clear all" utility interaction link found within the dashboard view.

5. Binding Acceptance

By engaging the application loops or interacting with the processing components of the site, you formally accept the diagnostic rules, network pipelines, and operational limits outlined inside this Privacy Policy architecture.
